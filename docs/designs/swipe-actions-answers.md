# Swipe actions: the owner's answers (2026-11-14)

Recorded before any design work, so they do not live only in a chat.

1.  Scope: both "pick the action for each existing swipe" and "add new swipes".
2.  New swipes on the left and right edges: long swipe, swipe and hold, and
    a top half and bottom half with their own actions. All three.
3.  Existing swipes (side Back, bottom Home, bottom pause Recents):
    everything can be changed, Home included. If Home and Back are both
    removed the app warns but allows it.
4.  Extra actions for the picker, on top of the corner list: Previous app;
    Back, Home, Recents; Torch on/off. Media and volume were not picked.
